## Edge compatibility findings

- `@ratelock/core` and `@ratelock/local` use web-compatible primitives, but local state remains isolate-local and is not a globally shared edge limiter.
- The current Redis integrations target node-redis, ioredis, and Bun's native Redis client; no fetch-based Redis client is supported by the current adapter.
- PostgreSQL is more nuanced: Cloudflare Workers supports PostgreSQL through Hyperdrive and compatible `pg` or `postgres` versions. RateLock has not validated this combination as a supported runtime, and the Postgres package's periodic cleanup timer currently assumes Node-style `unref()` timers.
- Upstash REST is a viable future Redis integration, but its HTTP API is vendor-specific rather than a universal Redis-over-HTTP standard. A dedicated adapter package is the most honest initial design.
