# BLOG-02 — Polish blog hero, cards, and slop-free prose

## What was done
- **UI/UX audit:** Blog index hero was a single `h1` + flat grid with `bg-fd-card` cards; no hierarchy, no featured treatment, no filtering, monotone typography. Cards used `text-sm leading-*` non-canonical and lacked visual anchors. Applied `frontend-design` + `ui-ux-pro-max` reasoning.
- **New editorial hero:** `src/app/(home)/blog/page.tsx` now has a two-column hero with `pattern-grid` + radial halos (`bg-background` + primary/secondary), `font-heading` 34/46px headline with `text-gradient` accent, badge `Engineering notes · N guides`, subhead, CTA row (`Browse docs`, `Open simulator`, `RSS feed`), and a right `Pick a path` panel with tag filter chips (`All` + dynamic tag set) and stats (Strategies/Engines/Frameworks). `searchParams: Promise<{tag?:string}>` drives server filtering; fallback to `All`. Hero respects `pattern-grid` and `dark` tokens from `globals.css`.
- **Featured guide:** When no tag filter, the most recent post renders as a 12-col horizontal card: left text (Featured pill, date·readingTime, title `text-2xl/tight`, description, tags), right code panel (`ratelock.ts` mono preview with `fixedWindow` snippet) on `bg-muted/40` + `pattern-grid`. Hover lifts with `-translate-y-0.5` + `shadow-md`.
- **Card system:** Remaining posts in `md:grid-cols-2 xl:grid-cols-3` with `h-1 bg-linear-to-r from-primary via-primary/60 to-secondary` top accent, `text-[11px]` uppercase tag·date, `font-heading text-[16px]/tight`, `text-sm/5` description clamp, `rounded-full bg-muted` tag pills, author·readingTime footer with `→` circle that inverts on hover. Tags use `tag` param for deep linking; empty state shows dashed border + `Show all`.
- **Post page polish:** `src/app/(home)/blog/[slug]/page.tsx` got an editorial header with halo, breadcrumb, tag pills, `text-[30px]/[1.05]` title, author avatar (initials), readingTime, ShareButton + Docs CTA, then `InlineTOC` + MDX. Added `Related` 2-card grid at bottom sorted by date. ReadingTime helper centralised.
- **Prose overhaul:** Rewrote all 9 MDX posts with `stop-slop` + `documentation-writer`:
  - Cut throat-clearers (`Here's the thing`, `This guide shows`), emphasis crutches, adverbs, em dashes, meta-commentary (`In this section we'll`), false agency, passive voice. Replaced with active voice and human subject (“You …”).
  - Removed binary contrasts and dramatic fragmentation; stated points directly.
  - Applied Diátaxis: 7 How-to Guides (Hono/Express/Fastify/NestJS/Bun) and 2 Explanations (Token Bucket vs Sliding Window, Redis down). Each now states user goal, immediate steps, and scoped next steps with internal links.
  - Descriptions trimmed of em dashes, titles kept, dates/tags intact. Code snippets unchanged.

## Key decisions
- **Filter via `searchParams` (server):** Shareable `?tag=redis` URLs for SEO; hero shows `{filtered.length} shown`. Trade-off: `/blog` becomes dynamic `ƒ` (see build: `ƒ /blog`) vs previous static `○`. Acceptable for editorial surface; can be moved to client `useState`/`nuqs` later to restore static while keeping instant filter if needed.
- **No emoji icons, no new deps:** Kept `@iconify/react` available but used dot + gradient bar for visual anchors to stay on brand (teal `primary`, amber `secondary`, `pattern-grid`). Avoided extra `feed` dep; RSS stays manual.
- **Canonical Tailwind:** Fixed `text-sm leading-5` → `text-sm/5`, `text-2xl leading-tight` → `text-2xl/tight`, `bg-gradient-to-r` → `bg-linear-to-r`, double spaces, etc., to satisfy `better-tailwindcss` canonical rules. Adopted `oxfmt --write → oxlint --fix` pipeline; lint is gated, format intentionally reports.
