3. **Two real defects found and fixed** (exactly what TST-02 was for):
   - *Sliding-window duplicate-id batches* (postgres, both drivers): the batch CTE inserts every input row in one statement, so duplicates resolved against the same pre-insert snapshot — identical `remaining` instead of accumulating. Redis/local pass; postgres diverged. Fix: Set-dedup sequential fallback mirroring counter strategies. Caught by the new contract against the REAL database.
   - *`PgPoolLike` rejected real `pg.Pool`*: pg v8's overloaded signatures never satisfied the narrow structural type — passing a Pool via `pool` failed to compile. Hidden until now because the pool path had zero coverage. Fix: accept natural call shapes.
4. Process lesson: integration runs consumed the BUILT `@ratelock/test-utils` dist — contract edits are invisible to integration suites until `test-utils` is rebuilt. First "regression" observed after hardening was actually stale dist.
